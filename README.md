# System Monitor

Десктопный монитор системы на **Python + PySide6 (Qt)** с тёмной темой, живыми графиками и круговыми индикаторами. Показывает нагрузку CPU, память, диск, скорость сети и топ процессов в реальном времени.

![preview](preview.png)

## Возможности

- 🔵 **Круговые гейджи** — CPU, Memory, Disk с процентами и деталями (частота, объём)
- 📈 **Живые графики** — загрузка CPU и скорость сети с плавной линией и градиентной заливкой (кастомная отрисовка через `QPainter`)
- 🌐 **Карточка сети** — скорость download / upload в реальном времени
- 📋 **Топ процессов** — сортировка по загрузке CPU
- ⏱️ **Аптайм и инфо о системе** — hostname, ОС, модель CPU, ядра/потоки
- 🎨 **Тёмная тема**, минималистичный дизайн, плавное обновление раз в секунду

## Технологии

- **PySide6** — GUI (официальный Qt для Python)
- **psutil** — сбор системных метрик
- **QPainter** — кастомная отрисовка графиков и гейджей

## Установка и запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить
python main.py
```

> Windows 11 / 10, Python 3.9+

## Как это работает

Два таймера `QTimer` обновляют интерфейс: быстрый (раз в секунду) для метрик и графиков, медленный (раз в 2 сек) для списка процессов. Метрики берутся из `psutil`, скорость сети считается как разница счётчиков байт за интервал. Графики и гейджи полностью нарисованы вручную через `QPainter` — поэтому легко кастомизировать цвета и стиль.
